# Survey Feedback Analyzer 

A simple Python project I built to practice Python fundamentals by analyzing customer survey feedback. 

## What this project does:
* **Starts with sample data:** Loads a dictionary with 10 preloaded customer feedback entries (including names, comments, and ratings from 1 to 5).
* **Takes user input:** Asks the user to add new feedback entries interactively and automatically updates the serial numbers.
* **Cleans the text:** Removes punctuation (like `.`, `,`, `!`), fixes extra spaces, and converts everything to lowercase.
* **Counts keywords:** Uses a custom function to check how many feedback comments contain specific words like "good", "poor", or "excellent".
* **Shows final insights:** Calculates the average rating, finds the longest comment, lists all unique words without duplicates, and sorts the feedback from highest to lowest rating.

##  Tools Used:
* Python 3
* Jupyter Notebook

##  How to Run:
1. Open **Jupyter Notebook** on your computer.
2. Open the `Survey_Feedback_Analyzer.ipynb` file.
3. Run the cells one by one from top to bottom!
